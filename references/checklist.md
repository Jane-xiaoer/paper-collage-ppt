# 交付前检查清单

生成完 deck 逐项过。P0 不过不许交付。

## P0 · 硬伤(必须全过)

- [ ] `grep '\[必填\]' index.html` 无残留占位文字(含 `<title>`)
- [ ] 全部文字都是真 HTML——插画里没有任何 AI 画的文字(乱码高危)
- [ ] 没有绕过主题系统写死颜色(新颜色必须进 body.tN 变量)
- [ ] 同页纸片角度互不相同、正负交替;没有一页所有纸片摆正
- [ ] 同页多张纸片剪裁轮廓不全同(默认/cut2/cut3 轮换)
- [ ] 胶带/订书钉全部贴在 `.pin` 里 `.piece` 外(贴进 piece 会被剪掉)
- [ ] `<body class="tN">` 初始主题按内容气质定过(不是随手留 t1);换肤面板试切 3-4 套(含一个深色)确认内容都可读
- [ ] 阴影全走 `--lift-f/--lift-f-high` 变量,无自写阴影、无第二光源
- [ ] 带 r 类且带 data-drop 的纸片都写了 `style="--rot:..."`(否则入场后旋转丢失)
- [ ] 无 emoji(手写体符号 ✓ 允许);图标用内联 SVG 手绘风(参考 arrow-hand)
- [ ] 中文大标题不出现一字一行(过长就手动 `<br>` 断行)
- [ ] 底色节奏:无连续 3 页同底色;8 页以上有 ≥1 个 ink 页

## P1 · 风格(强烈建议全过)

- [ ] 每页只说一件事;单页文字量 ≤ 5 行正文
- [ ] 每页有至少一个手工痕迹(胶带/纸屑/手写字/撕边),但不超过三种
- [ ] 插画全部同一批配方生成、同一风格锚,没有混入照片/立体渲染/别的画风
- [ ] 插画调色板和选定主题一致(themes.md 联动表)
- [ ] 手写体只出现在标点、强调词、勾选符——没有整句手写
- [ ] 留白充足:纸片总面积不超过版面 60%

## P2 · 体验

- [ ] 浏览器实际翻一遍:键盘 ←→ / 滚轮 / 圆点导航都正常
- [ ] 入场动画是逐格「贴」的手感(steps),没有被改成平滑 ease
- [ ] 图片都在 `images/` 相对路径,单张 ≤ 800KB,总量 ≤ 10MB
- [ ] 断网打开版式不塌(字体降级可接受)

## 自检命令

```bash
grep -n '\[必填\]' index.html          # 占位残留
grep -c '<section class="slide' index.html   # 页数
grep -n 'class="slide' index.html      # 人工过底色节奏
open index.html                        # 真实翻一遍
```
